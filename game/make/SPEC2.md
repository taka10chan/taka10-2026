# A. 表記を 漢字にする

## A-1. なぜ

使う人（中学生）から「なんで UI ひらがななの？」と言われた。
そのとおりで、こちらが「やさしく」と指示しすぎて**子ども扱いした画面**になっていた。
中学生は漢字を読める。ひらがなだらけは、やさしいのではなく**読みにくく、失礼**。

さらに、使う人が最初に出した例は **`動かす(0,0,3)`** で、**漢字**だった。
それをこちらがひらがなに変えていた。本人の言った形に戻す。

## A-2. 方針

| どこ | どうする |
|---|---|
| 画面の文字（ボタン・見出し・案内） | **ふつうの日本語**。漢字を使う。「ほぞんずみ」→「保存済み」 |
| エラーの文 | **ふつうの日本語**。「5ぎょうめ」→「5行目」 |
| 単語帳の説明 | **ふつうの日本語**。ですます調は そのまま |
| 組み込みのことば | **漢字を正式**にする。ひらがなも **今までどおり動く**（別名） |
| 文法のキーワード | **漢字を正式**にする。ひらがなも 動く |
| 色・キーの名前 | **漢字を正式**にする。ひらがなも 動く |

**大事**: ひらがなを消してはいけない。今あるコードが動かなくなる。
**両方 受けつけて、表に出すときは漢字**。

読みやすさのための分かち書き（「ものが たりません」の空白）は やめる。
ふつうに「ものが足りません」と書く。ただし**コードの中の空白は 文法なので そのまま**。

## A-3. 文法キーワードの漢字（lang.js）

| ひらがな（今） | 漢字（正式にする） |
|---|---|
| くりかえし | 繰り返し |
| かい | 回 |
| まいかい | 毎回 |
| はじめに | 最初に |
| おしたとき | 押したとき |
| てじゅん | 手順 |
| かえす | 返す |
| ぬける | 抜ける |
| つぎへ | 次へ |
| おわり | 終わり |

そのまま（漢字にしない）: もし / なら / そうでなければ / そうでなくもし /
のあいだ / ずっと / ひとつずつ / かつ / または / ではない / はい / いいえ / なし

## A-4. 組み込みのことばの漢字（runtime.js）

`builtins()` は **両方のつづりを返す**（同じ関数を2つのキーに入れるだけ）。

つくる: `箱`=はこ `玉`=たま `筒`=つつ `看板`=かんばん `自分のモデル`=じぶんのモデル
`消す`=けす `全部消す`=ぜんぶけす

うごかす: `動かす`=うごかす `置く`=おく `前へ`=まえへ `後ろへ`=うしろへ
`右へ`=みぎへ `左へ`=ひだりへ `上へ`=うえへ `下へ`=したへ
`回す`=まわす `傾ける`=かたむける `向ける`=むける `向かせる`=むかせる

みため: `色`=いろ `大きさ`=おおきさ `隠す`=かくす `見せる`=みせる
`模様`=もよう `空の色`=そらのいろ `地面`=じめん `霧`=きり

物理: `重力`=じゅうりょく `壁にする`=かべにする `速さ`=はやさ
`ジャンプ`（そのまま）`床にいる`=ゆかにいる

アニメ: `アニメ`（そのまま）`アニメを止める`=アニメをとめる
`プレイヤーの姿`=プレイヤーのすがた

カメラ: `カメラを置く`=カメラをおく `カメラを向ける`=カメラをむける
`カメラを向かせる`=カメラをむかせる `カメラを付ける`=カメラをつける
`カメラの中に`=カメラのなかに `マウスで見回す`=マウスでみまわす `カメラの向き`=カメラのむき

しらべる: `押されてる`=おされてる `押した`=おした `ぶつかってる`（そのまま）
`距離`=きょり `画面の横`=がめんのよこ `画面の縦`=がめんのたて
`マウスX` `マウスY` `クリックした` `クリック中`=クリックちゅう

すうじ: `乱数`=らんすう `整数`=せいすう `絶対値`=ぜったいち
`最大`=さいだい `最小`=さいしょう `平方根`=へいほうこん
`サイン` `コサイン` `角度`=かくど

もじ/リスト: `つなげる`（そのまま）`長さ`=ながさ `加える`=くわえる `取り除く`=とりのぞく

そのた: `書く`=かく `待つ`=まつ `音`=おと `点数`=てんすう
`メッセージ`（そのまま）`ゲーム終了`=ゲームしゅうりょう `時間`=じかん `止める`=とめる

最初からあるもの: `プレイヤー` `地面`… ← **`ちめん` は `地面` に。ただし
`じめん()`（地面を作る関数）と名前がぶつかるので、
関数のほうを `地面を作る`／`じめんをつくる` に改名し、
最初からある床の変数を `地面`／`ちめん` にする。**

そうさ: `操作を切る`=そうさをきる `プレイヤーを消す`=プレイヤーをけす
`速さを変える`=はやさをかえる `一人称`=いちにんしょう

## A-5. 色とキーの名前

色: `赤 青 緑 黄 白 黒 水色 ピンク オレンジ 紫 灰色 茶色 紺`
（`あか あお みどり きいろ しろ くろ みずいろ むらさき はいいろ ちゃいろ こん` も動く）

キー: `右 左 上 下 スペース エンター シフト`
（`みぎ ひだり うえ した` も動く）

## A-6. ものの見えるフィールド

`x y z 横 高さ 奥行き 色 向き 傾き 見える`
（`よこ たかさ おくゆき いろ むき かたむき みえる` も 今までどおり動く）

## A-7. エラーの文（例。この調子で全部書きかえる）

    5行目: 「ゆうしゃ」という変数はまだありません。
      → 先に  ゆうしゃ = 箱(0, 5, 0, 4, 4, 4)  のように作ってください

    12行目: 「動かす」に渡すものが足りません（4つ必要です）。
      → 使い方: 動かす(もの, x, y, z)

    8行目: 「もし」に対応する「終わり」がありません。
      → ブロックの最後には 終わり を書きます

# B. ワールド と スクリプト（ロブロックス・スタジオの形にする）

## B-1. なぜ

使う人の言葉:

> 四角いパーツとか丸いパーツとか、作る場所がないし、
> ワールドにあるものの一覧をつくったら分かりやすいと思う。
> そこにスクリプトとかを入れて動かすといいと思うし、当たり判定とかは？

今のことだまは**コードを書かないと何も置けない**。スタジオは逆で、
まず置いて、選んで、設定して、必要ならスクリプトを入れる。そこに寄せる。

## B-2. さくひんの形（`localStorage['kotodama-works']`）

```json
{
  "id": "w1",
  "name": "はじめての作品",
  "main": "…ワールド全体のコード…",
  "objects": [
    {
      "id": "o1",
      "名前": "ゆか",
      "形": "箱",
      "モデル": null,
      "x": 0, "y": 0, "z": 0,
      "横": 40, "高さ": 1, "奥行き": 40,
      "向き": 0, "傾き": 0,
      "色": "#7ec850",
      "壁": true,
      "重力": false,
      "見える": true,
      "コード": ""
    }
  ],
  "updated": 1756300000000
}
```

- `形` は `"箱"` `"玉"` `"筒"` `"モデル"` のどれか
- `玉` は `横` を直径として使う。`筒` は `横` が直径、`高さ` が高さ
- `モデル` は `形` が `"モデル"` のときだけ、モデリング部屋のモデル名
- **古いさくひん（code だけの文字列や `{name, code}`）は `main` に移す**。
  読みこみのときに自動で直すこと。データを失わない。

## B-3. ワールドのものは そのまま変数になる

ワールドに「あかい箱」という名前のものがあれば、コードで

    色(あかい箱, "青")

と、**いきなり名前で書ける**。名前は画面側が保証する:
- 空白・記号・数字はじまりを禁止
- 同じ名前を2つ作らせない
- 予約語（もし・終わり・箱 など組み込みのことば）と同じ名前を禁止

見つからないとき用に `探す("名前")`／`さがす("なまえ")` も用意する。

## B-4. ものごとのスクリプト

- ワールド全体のコード（`main`）は 今までどおり
- **もの1つ1つに コードを入れられる**。その中では `自分`（`じぶん`）が そのもの
- ものの コードでも `毎回` `ずっと` `押したとき` `手順` が使える
- **変数と手順は 全部で共有**（main も ものの コードも 同じものを見る）
- 動く順番: ワールドのものを全部作る → `main` → 各ものの コード（一覧の上から順）

### 新しいできごと: `触れたとき`

    触れたとき (相手)
      もし 相手 == プレイヤー なら
        点数(点 + 1)
        消す(自分)
      終わり
    終わり

- ひらがな別名: `さわったとき`
- 別のものが 当たった しゅんかんに 1回だけ走る
- `相手` には 当たった相手が入る（名前は 使う人が自由につけられる）
- **`壁` が OFF でも鳴る**（すり抜けながら反応できる。コイン等に使う）
- 同じ相手とは **0.25秒に1回まで**（連打を防ぐ）
- ワールド全体のコード（`main`）では使えない（ものの コード専用）

## B-5. 当たり判定（使う人の質問への答え）

チェックボックスで切りかえる:

| 設定 | いみ |
|---|---|
| **壁**（通れない） | ON なら すり抜けできない。プレイヤーも 重力のあるものも 止まる |
| **重力**（落ちる） | ON なら 落ちる。床（壁 ON）に乗る |
| **見える** | OFF なら 見えないが 当たり判定は残る（見えない壁が作れる） |

コードからも今までどおり `壁にする(もの)` `重力(もの, はい)` `ぶつかってる(A, B)`。

## B-6. 画面（index.html）

```
┌──────────────────────────────────────────────────────┐
│ ことだま  ▶プレイ ■ストップ  サンプル▾ 単語帳 部屋… 作品▾  │
├────────────┬───────────────────┬────────────────────┤
│ ワールド     │                   │                    │
│  ├ 地面      │   ゲーム画面        │   コードを書く所     │
│  ├ ゆか      │   （3D）           │  [ワールド][ゆか]    │
│  └ あかい箱  │                   │                    │
│            │                   │                    │
│ ＋箱 ＋玉    ├───────────────────┤                    │
│ ＋筒 ＋モデル │   ログ・エラー      │                    │
├────────────┤                   │                    │
│ 設定         │                   │                    │
│  名前 [    ] │                   │                    │
│  位置 x y z  │                   │                    │
│  大きさ      │                   │                    │
│  色  ■       │                   │                    │
│  ☑壁 ☐重力  │                   │                    │
└────────────┴───────────────────┴────────────────────┘
```

- **ワールド一覧**: ものを並べる。クリックで選択。名前の右に、コードが
  入っているものは `📄` を出す。ドラッグで並べかえは要らない
- **＋ボタン**: 箱・玉・筒・モデル。**プレイヤーの前あたり**に置いて、
  すぐ選択状態にする。名前は「箱1」「箱2」…と自動でつける
- **設定**: 名前 / x y z / 横 高さ 奥行き / 向き 傾き / 色 / 壁 重力 見える。
  数字は入力欄。**ドラッグでも増減できる**と気持ちいい（できれば）
- **コード欄のタブ**: 「ワールド」と、選んでいるものの名前。
  ものを選ぶと そのもののコードに切りかわる
- **複製・削除**（Ctrl+D / Del）
- **止まっているときは、ゲーム画面でものをクリックして選べる**。
  選んだものは 枠が光る。やじるしキーで動かせなくてよい（設定の数字で動かす）
- 幅が狭いときは、ワールド一覧を畳めるようにする

## B-7. 動きの決まり

- ▶ プレイ を押すと、ワールドのものを作り直してから コードを動かす
- ■ ストップ で 元の位置に戻る（**遊んで動いた結果を保存しない**。
  スタジオと同じ。ここを間違えると作ったものが壊れる）
- ものの追加・設定変更・コードの変更は **自動保存**（今までどおり1秒）

# C. プレイヤーを R15 アバターにする

使う人の言葉:

> やっぱり、キャラクターはロブロックスの R15 アバターみたいな感じにしてくれない？

いまの丸っこいカプセル人間をやめて、**ロブロックスの R15 と同じ 15 パーツ**にする。
これは見た目だけの話ではない。R15 なら**アニメ部屋で関節ごとに動かせる**ので、
「歩くアニメは自分で作る」という本人の希望がそのまま叶う。

## C-1. 新しいファイル `src/avatar.js`

runtime.js が大きいので、アバターだけ別ファイルにする。

```js
import * as THREE from '../../lib/three.module.js';

/**
 * R15 のアバターを作る。
 * @param  {object} 色  { はだ, シャツ, ズボン } 省略可
 * @return {{ group, parts, 高さ, 半径 }}
 *   group … THREE.Group（足元が y=0、正面は -z）
 *   parts … { "頭": Object3D, "上胴": …, … } 下の15個ちょうど
 *   高さ  … 5.0（足元から頭のてっぺんまで）
 *   半径  … 1.0（当たり判定の横幅の半分）
 */
export function buildR15(色);

/** 歩きの見本ポーズ（runtime が既定で使う。使う人が自分のアニメを入れたら止まる） */
export function 歩きポーズ(parts, t);   // t は 0〜1 の周期
```

## C-2. 15 パーツの名前（この日本語名で固定する）

ロブロックスの R15 と1対1で対応させる。アニメ部屋の `part` 番号は
**この順番（0〜14）**に対応する。

| # | 日本語名 | Roblox | おおよその大きさ (横×高さ×奥行き) |
|---|---|---|---|
| 0 | 頭 | Head | 1.20 × 1.10 × 1.20 |
| 1 | 上胴 | UpperTorso | 1.60 × 1.00 × 0.85 |
| 2 | 下胴 | LowerTorso | 1.55 × 0.60 × 0.85 |
| 3 | 右上腕 | RightUpperArm | 0.55 × 0.85 × 0.55 |
| 4 | 右前腕 | RightLowerArm | 0.52 × 0.75 × 0.52 |
| 5 | 右手 | RightHand | 0.55 × 0.35 × 0.55 |
| 6 | 左上腕 | LeftUpperArm | 0.55 × 0.85 × 0.55 |
| 7 | 左前腕 | LeftLowerArm | 0.52 × 0.75 × 0.52 |
| 8 | 左手 | LeftHand | 0.55 × 0.35 × 0.55 |
| 9 | 右腿 | RightUpperLeg | 0.60 × 0.90 × 0.62 |
| 10 | 右脛 | RightLowerLeg | 0.57 × 0.80 × 0.60 |
| 11 | 右足 | RightFoot | 0.62 × 0.35 × 0.75 |
| 12 | 左腿 | LeftUpperLeg | 0.60 × 0.90 × 0.62 |
| 13 | 左脛 | LeftLowerLeg | 0.57 × 0.80 × 0.60 |
| 14 | 左足 | LeftFoot | 0.62 × 0.35 × 0.75 |

## C-3. 組み立て方（ここが大事）

- **親子関係を作る**。肩を回せば腕全体が動くようにする。
  ```
  下胴
   ├ 上胴
   │   ├ 頭
   │   ├ 右上腕 ─ 右前腕 ─ 右手
   │   └ 左上腕 ─ 左前腕 ─ 左手
   ├ 右腿 ─ 右脛 ─ 右足
   └ 左腿 ─ 左脛 ─ 左足
  ```
- **回転の中心は関節の位置**にする（肩・肘・手首・股・膝・足首）。
  Object3D を関節の位置に置き、その子として Mesh を下向きにずらして入れる。
  こうすると `parts["右上腕"].rotation.x = 0.5` で肩から素直に振れる。
- 角は丸める。`RoundedBoxGeometry` は無いので、**面取りした BoxGeometry を自作**するか、
  少し小さい箱＋各辺に細い箱／球で角を作るのではなく、
  **`BoxGeometry` の頂点を寄せて面取りする**簡単な関数を書く（半径 0.06 くらい）。
  カクカクの直方体そのままにはしない。ロブロックスの角も丸い。
- 色: はだ `#f2c9a0`、シャツ `#3a7ad6`、ズボン `#37414d`。
  頭・手はだ色、上胴/腕はシャツ色、下胴/脚はズボン色、足は靴っぽく暗く。
- 顔をつける。目2つ（黒い小さい箱）と口（うっすら）。**正面は -z**。
- 全体の高さ 5.0、当たり判定は 2.0 × 5.0 × 2.0 くらいの箱。

## C-4. runtime.js 側

- 既定のプレイヤーを `buildR15()` で作る
- `プレイヤーの姿("なまえ")` を呼ぶまでは `歩きポーズ()` を使う。
  呼んだら今までどおり止める
- **`アニメ(プレイヤー, "なまえ")` が、既定の R15 にも効く**ようにする。
  アニメの `track.part` 番号を C-2 の 0〜14 に対応させる
- モデリング部屋に **「R15」という見本モデルを最初から入れておく**と、
  アニメ部屋でそのまま歩きを作れる（画面側の担当に伝える）

# D. 手でつかんで動かす（スクリプトを書かなくても）

使う人の言葉:

> モデルの大きさとか、移動とかもスクリプトじゃなくてもできるようにしてほしい。
> （スクリプトで、物を動かしたりってのはできるようにしてほしいな）

**両方できる**のが正解。スタジオと同じで、
- 止まっているとき … ゲーム画面で**つかんで動かす・大きくする・回す**
- 動いているとき … スクリプトが動かす

## D-1. 新しいファイル `src/edit.js`

3D の中身は runtime.js が持っているので、編集の道具だけ別ファイルにする。
モデリング部屋（`src/model.js`）に**同じものがもう出来ている**。
**あれを土台にすること。**（読むだけ・書きかえない）

```js
export class Editor {
  /** @param game runtime.js の Game。scene / camera / canvas を使う */
  constructor(game);

  有効(on);                    // 止まっているときだけ true
  選ぶ(id);                    // id は ワールドのものの id。null で解除
  道具(name);                  // '移動' | '大きさ' | '回転'
  更新(id, patch);             // 設定パネルの数字が変わったとき 3D に反映
  こわす();                    // 片づけ

  onSelect = (id) => {};       // 画面でクリックして選ばれた（null もありうる）
  onChange = (id, patch) => {};// ドラッグで変わった。patch は
                               //   { x, y, z } / { 横, 高さ, 奥行き } / { 向き, 傾き }
}
```

## D-2. できること

- **クリックで選ぶ**。選んだものは 黄色い枠が光る
- **矢印をつかんでドラッグ**すると動く（移動）
- **W / E / R** で 移動・大きさ・回転 を切りかえ
- **グリッドにそろう**（0.25 きざみ。回転は 15度）。切りかえられる
- **Ctrl+Z / Ctrl+D / Del**
- **カメラを飛ばせる**（右ドラッグで見回す、右＋WASD/QE で飛ぶ、
  中ドラッグで平行移動、ホイールで寄る、F で選んだものに寄る）
- 指でも触れる（1本で見回す、タップで選ぶ、矢印を指でつまむ）
- **左クリックのドラッグで画像のゴーストが出ない対策**を必ず入れる

## D-3. runtime.js が出すもの

edit.js が使えるように、`Game` に次を足す（読み取り専用でよい）:

    game.scene      THREE.Scene
    game.camera     THREE.Camera
    game.canvas     canvas 要素
    game.世界のもの  Map<id, もの>   ← buildWorld で作ったもの。id で引ける

## D-4. 動きの決まり

- **止まっているとき**も 3D 画面は出しっぱなし（暗くしない）。
  ワールドのものが見えていて、いつでも触れる
- ▶ プレイ を押したら 編集は切れて、カメラはプレイヤーを追う
- ■ ストップ で また触れるようになり、**ものは元の位置に戻る**
- ドラッグで動かしたら `onChange` → 画面側が さくひんに保存し、設定の数字も更新

# E. 左クリックと右クリックを分ける

使う人の言葉:

> 左クリックしたら見たいのも分けて作んないと、クリックだけだったら右クリックにも反応しちゃう。

**本当にバグ。** `runtime.js` の `mousedown` が `e.button` を見ていないので、
右クリックでも中クリックでも `クリックした()` が真になっている。

## E-1. 直しかた

| ことば | いみ |
|---|---|
| `クリックした()` | **左**クリックした瞬間。※今までの名前のまま、**左だけ**にする |
| `左クリックした()` | 同じ（はっきり書きたいとき） |
| `右クリックした()` | 右クリックした瞬間 |
| `中クリックした()` | ホイールを押した瞬間 |
| `クリック中()` | **左**を押しっぱなし |
| `左クリック中()` `右クリック中()` `中クリック中()` | 同様 |

ひらがな別名: `ひだりクリックした` `みぎクリックした` `なかクリックした`
`クリックちゅう` `ひだりクリックちゅう` `みぎクリックちゅう` `なかクリックちゅう`

- `e.button` は 0=左 1=中 2=右
- **右クリックで左が反応しないこと。逆も。** ここが直したいところ
- 右クリックのメニューは今までどおり止める（`contextmenu` の preventDefault）
- ポインタロックを頼むのは**左クリックのときだけ**
- 指（タッチ）は**左クリック扱い**にする
- `mouseup` も `e.button` を見て、押したボタンだけ離す
  （今は `mouseup` で全部 false にしているので、左を押しながら右を離すと左まで消える）

# F. ひらがな・カタカナ・漢字、どれでも通す

使う人の言葉:

> カタカナとか、平仮名とか、漢字があるから、それでも対応できるようにしてほしい。

日本語で書く以上、これは避けて通れない。`ハコ` と `はこ` と `箱` は同じもの。

## F-1. やりかた（lang.js）

名前を探すとき、**2段階**にする。

1. まず**そのままの字**で探す（速い。ふつうはここで見つかる）
2. 見つからなければ**そろえた形**で探す

「そろえた形」＝ **カタカナをひらがなに直したもの**。

    ハコ    → はこ
    ウゴカス → うごかす
    アニメ   → あにめ
    メッセージ → めっせーじ

組み込みのことばは、登録するときに**そろえた形の索引も一緒に作っておく**。
`アニメ` は `あにめ` として索引に入るので、使う人が `あにめ` と書いても見つかる。
`はこ` は `はこ` のまま索引に入るので、`ハコ` と書いても見つかる。**両方向に効く。**

漢字はそのまま登録されている（`箱` `動かす`）ので、そのままで見つかる。

## F-2. どこに効かせるか

- **組み込みのことば**（`箱` `動かす` …）… 効かせる
- **文法のキーワード**（`もし` `終わり` `繰り返し` …）… 効かせる（`オワリ` でも通る）
- **色とキーの名前**（`"赤"` `"あか"` `"アカ"` / `"右"` `"みぎ"` `"ミギ"`）… 効かせる。
  これは runtime.js 側。文字列の中身なので lang.js ではなく runtime.js が直す
- **使う人が作った変数・手順**… 効かせる。
  `コイン = 0` と書いたあとに `こいん` と書いても同じものを指す。
  厳密には別物にしたくなるが、**打ち間違いで詰まるほうがずっと困る**ので通す

## F-3. 気をつけること

- カタカナ→ひらがなの変換は、**小さい字（ッ ャ ュ ョ ァ…）と長音符（ー）も**正しく扱う。
  `ー` は そのまま `ー` にする（`メッセージ` → `めっせーじ`）
- `ヴ` は `ゔ`。`ヷ ヸ ヹ ヺ` は そのまま（まず出てこない）
- 半角カタカナ（`ﾊｺ`）も 全角カタカナに直してから そろえる。
  これは A章の正規化と同じ場所でやるとよい
- **そのままの字での一致を必ず優先する**。うっかり別のことばに当たらないように
- **打ち間違い検出（もしかして…）も、そろえた形で比べる**

## F-4. 単語帳

`tags` に**カタカナのつづりも**入れる。使う人がカタカナで検索するかもしれない。

# G. 予測変換（コード補完）

使う人の言葉:

> 文字を打ったら、予測変換？たとえば、もしって打ちたいとき、もって打ったら、
> 予測変換みたいのが出てきて、もしが出てくるようにしたらめっちゃいいんじゃね？
> でも、予測変換は、たとえばもって打ったら、もの下に、もしかして、もしって
> 打ちたいですか？みたいのが出てきて、スペース押してエンター押すと、
> それが出てくるようにしたらいいかも！！

ことばが 87語 ＋ 文法 25個ある。**覚えられるわけがない。**
単語帳を開けば分かるが、書いている手が止まる。打ちながら出るのがいちばん良い。

## G-1. 動き

1. コードを打つ。カーソルの直前の文字のかたまり（＝打ちかけの語）を見る
2. 当てはまることばがあれば、**カーソルのすぐ下**に小さな一覧を出す
3. **スペース**を押すと候補が選ばれる（もう一度押すと次の候補へ）
4. **エンター**で入る
5. **Esc** か 別の字を打つと消える

ほかにも: **↓ ↑** で選ぶ、**Tab** でも入る、**クリック／タップ**でも入る。

## G-2. いちばん大事なこと — 日本語入力の邪魔をしない

使う人は日本語入力（IME）で打つ。**変換中にキーを横取りしたら台無し**になる。

- `e.isComposing` が真、または `keyCode === 229` の間は**一切さわらない**
- 候補を作り直すのは `input` と `compositionend` のときだけ
- 一覧が出ていないときは、キーを一切横取りしない

**スペースの扱いに注意。** ことだまはキーワードの前後に空白が要る
（`もし てん > 10 なら`）。空白が打てなくなったら終わり。なので:

- 打ちかけの語が **ちょうどことばと同じ**（例: `もし` と打ち終えた）ときは、
  **スペースを横取りしない**（そのまま空白が入る）
- 打ちかけの語が **途中**（例: `も`）のときだけ、スペースで候補を選ぶ
- 候補を選んでいない状態のエンターは、**ふつうの改行**

## G-3. 何を候補に出すか

- 組み込みのことば 87語（漢字・ひらがな・カタカナの**全部のつづり**）
- 文法 25個（`もし` `繰り返し` `終わり` など）
- **ワールドに置いたものの名前**（`箱1` `コイン1` など）
- **そのコードの中で使う人が作った変数と手順**
- 色の名前とキーの名前（`"` の中を打っているときだけ）

## G-4. 探しかた（ここが肝心）

**読みで探せること。** `うご` と打って `動かす` が出ないと意味がない。

1. 打ちかけの語と、候補の**どれかのつづり**が前方一致 → いちばん上
2. **そろえた形**（カタカナ→ひらがな）どうしで前方一致 → 次
   - `lang.js` が `そろえた形()` を export しているので使うこと
   - 漢字のことばには**読み**（ひらがな）を持たせる。`words.js` の `tags` に
     ひらがなとカタカナが入っているので、そこから拾える
3. 途中に含む → その次
4. どれも当たらなければ、**距離1のあいまい一致**（もしかして）
   - 使う人の言う「もしかして、もしって打ちたいですか？」がこれ

並べる順: 短いことば優先 → よく使うもの優先。**8個まで**。

## G-5. 見た目

```
  もし ┃
  ┌──────────────────────────────────┐
  │ もし        もし ◯◯ なら … 終わり  │ ← 選ばれている行は色つき
  │ 文字         もじ(x, y, テキスト)   │
  │ 模様         もよう(もの, 名前)     │
  └──────────────────────────────────┘
   スペースで選ぶ  エンターで入れる  Escで閉じる
```

- **カーソルのすぐ下**に出す（textarea のカーソル位置を測る。
  同じ字形の見えない div に同じ文字を入れて測る やりかたが確実）
- 画面の下にはみ出すときは、カーソルの**上**に出す
- 1行に「ことば」と「使いかた」。選ばれている行の下に説明を1行
- 種類が分かる色分け（ことば／文法／ワールドのもの／自分で作った変数）
- タブレットでも押せる大きさ（44px 以上）

## G-6. 入れるもの

`words.js` の `insert`（例: `箱(0, 5, 0, 4, 4, 4)`）をそのまま入れる。
文法は**かたまりごと**入れる:

    もし  なら
      
    終わり

入れたあと、**カーソルを書き足したい場所に置く**（`もし` なら条件の所、
`箱(` なら最初の数字の所）。ワールドのものと自分の変数は名前だけ。

## G-7. 新しいファイル `src/suggest.js`

```js
export class 予測 {
  /**
   * @param textarea コード入力欄
   * @param 語彙をとる () => 候補の配列（下の形）。打つたびに呼ばれるので軽くすること
   */
  constructor(textarea, 語彙をとる);
  更新();          // ワールドや作品が変わったとき呼ぶ
  とじる();
  こわす();
  onInsert = (語) => {};   // 入れたときに呼ぶ（保存などに使う）
}
```

候補1つの形:

```js
{
  語: '動かす',
  読み: ['うごかす', 'ウゴカス', '動かす'],   // 前方一致に使う つづり全部
  挿入: '動かす(もの, x, y, z)',
  カーソル: 4,                                 // 挿入後にカーソルを置く位置（省略可）
  説明: 'ものを x y z のぶんだけ動かします。',
  種類: 'ことば' | '文法' | 'ワールド' | '変数',
}
```

`style.css` にスタイルを足し、`app.js` から使う。

# H. クローンと倉庫

使う人の言葉:

> クローンってどうやって作るんだっけ？
> あと、なんか複製したいものとか、そういうのを入れる箱？ファイルみたいのも作ってほしいなー

いまは画面で Ctrl+D するしかない。**コードから増やせない**ので、弾も敵もコインも
作れない。ロブロックスの `Instance:Clone()` と `ReplicatedStorage` にあたるものを作る。

## H-1. 倉庫

ワールド一覧を**2つに分ける**。

```
ワールド
 ├ 最初からあるもの
 │   ├ 地面
 │   └ プレイヤー
 ├ 置いたもの          ← 画面に出る。今までどおり
 │   ├ 足場
 │   └ コイン1
 └ 倉庫                ← 画面に出ない。複製のもと
     ├ たま見本
     └ てき見本
```

- もの に **`場所`** を足す。`'ワールド'`（既定）か `'倉庫'`
- **倉庫のもの**は…
  - 画面に出ない（`見える` が真でも出ない）
  - 当たり判定なし・重力なし・`触れたとき` も鳴らない
  - **でも、名前でコードから使える**（変数になる）
- 一覧から **「倉庫へしまう」「ワールドへ出す」**で行き来できる
- ＋ボタンで直接 倉庫に作れてもよい

## H-2. クローン

| ことば | いみ |
|---|---|
| `クローン(もの)` | そのものと同じものを1つ作って**ワールドに出す**。→ 新しいもの |
| `複製(もの)` | 同じ（ひらがな別名 `ふくせい`） |

- 位置・大きさ・向き・色・`壁`・`重力`・`見える` を**そのまま写す**
- **倉庫のものをクローンすると、ワールドに出る**（これが主な使いかた）
- ワールドのものをクローンしてもよい
- **もとのものにコードが入っていたら、クローンでもそのコードが動く。**
  `自分` はクローン自身を指す。ここがいちばん大事
- 名前は `もと の名前 + 連番`（`たま見本2` `たま見本3` …）。変数にはしない
  （返ってきたものを使う人が変数に入れる）
- `消す(クローン)` は今までどおり
- 作りすぎ防止: ワールドのもの が 2000 を超えたら、日本語で警告して作らない

### 書きかたの例

```
# 倉庫に「たま見本」を置いておく（画面の一覧から）

押したとき ("スペース")
  たま = クローン(たま見本)
  置く(たま, プレイヤー.x, プレイヤー.y + 2, プレイヤー.z)
  向ける(たま, カメラの向き())
  速さ(たま, 0, 0, 0)
  重力(たま, はい)
終わり
```

## H-3. runtime.js の契約

```js
game.onClone = (新しいもの, もとのもの) => {};   // ← 新しく足す
```

- `クローン()` が新しいものを作ったら**すぐ**呼ぶ
- `app.js` がこれを受けて、もとのものの `コード` を `runner.attach()` する
  （`自分` は新しいもの）
- `game.世界のもの` にも入れる（`id` は新しく振る）
- `もの.__もとid` に もとの id を入れておく（app.js がコードを探すため）

`buildWorld(objects)` は `場所` を見る:
- `'倉庫'` のものは **見た目も物理も作らない**が、もの としては作って名前表に入れる
- `場所` が無いものは `'ワールド'` 扱い（古いデータでもこわれない）

## H-4. app.js のやること

- ワールド一覧を「置いたもの」と「倉庫」に分ける
- 設定パネルに **「倉庫へしまう」／「ワールドへ出す」** のボタン
- `game.onClone` をつないで、もとのもののコードをクローンにも `attach` する
- ＋ボタンで置いたあと、倉庫へ移せること
- 保存の形に `場所` が入る（省略時は `'ワールド'`）

## H-5. 画面で複製する（今もうある）

ものを選んで **Ctrl+D**、または設定パネルの「複製」ボタン。
**使う人はこれを知らなかった**ので、一覧のそばか設定パネルに
「Ctrl+D で複製」と**見えるように書いておくこと**。
