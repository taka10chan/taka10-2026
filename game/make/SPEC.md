## 2. 3D の きまり（いちばん大事）

- **y が うえ**（ロブロックスと同じ）。x が よこ、z が おくゆき。
- 単位は「スタッド」くらいの感覚。人の背は 5 くらい、地面は y=0。
- `もの` の `x, y, z` は **中心**。
- 角度は **度**（ラジアンではない）。`むき` は y軸まわり（左右を向く）、
  `かたむき` は x軸まわり（上下に倒す）。
- `むき = 0` のとき、その `もの` の **前は -z の方向**（three.js の既定と同じ）。
- カメラの初期位置は `(0, 14, 22)`、原点を見ている。視野角 70。

### 「もの」の見えるフィールド（読み書き両方できる）

    x  y  z  よこ  たかさ  おくゆき  いろ  むき  かたむき  みえる

lang.js のメンバアクセス（`ゆうしゃ.y`）はこの名前で来ます。
`もの` は素の JS オブジェクトにして、上の名前をそのままプロパティ名にするのが
いちばん簡単です（three.js の Mesh は `__mesh` のような別の名前で中に持つ）。
フィールドが書き換えられたら、次の描画までに Mesh へ反映すること。

## 3. runtime.js の export（契約。1文字も変えない）

```js
export class Game {
  constructor(canvas);   // canvas は 640x480（論理サイズ）
  reset();               // ものを全部消す、カメラと空を戻す、時間を0に
  builtins();            // → { 日本語名: 関数 }
  beginFrame(dt);        // ユーザーコードの前。入力の「押した瞬間」を確定
  endFrame();            // ユーザーコードの後。物理 → 描画 → 押した瞬間を消す
  attachInput();         // キー・マウス・タッチのイベント登録（1回だけ）
  onLog  = (text) => {};
  onStop = () => {};
  get stopped();
}
```

builtins は **ふつうの JS 関数**。戻り値が `{ __wait: 秒 }` なら待つ。
おかしな引数が来たら **日本語のメッセージだけの Error** を投げる
（行番号は lang.js がつける）。英語のエラーを絶対に外へ出さない。

## 4. かんたんな物理（これがあると3Dゲームが作れる）

参考: `C:\Users\tetsu\work\gun-arena\web\src\physics.js`（同じ人の FPS のもの）

### コードから さわる

`builtins()` が返すオブジェクトには、**関数でないもの**も入れてよいことに
します（lang.js 側で、関数でない値は最初からある「へんすう」になります）。

    プレイヤー   … もの（上のキャラクター）
    ちめん       … もの（床）

なので、いきなりこう書けます:

    プレイヤー.y = 20            # 空から落ちてくる
    いろ(プレイヤー, "あか")
    もし ぶつかってる(プレイヤー, てき) なら ...

さらに次のことばを足します:

| ことば | いみ |
|---|---|
| `そうさをきる()` | 自動の操作をやめる（自分で動かしたいとき） |
| `プレイヤーをけす()` | プレイヤーごと消す（見せるだけのものを作るとき） |
| `はやさをかえる(あるく, はしる, ジャンプ)` | 歩く速さなどを変える（既定 14 / 22 / 32） |
| `いちにんしょう(はい)` | 一人称に切りかえる |

`カメラをつける` `カメラのなかに` `マウスでみまわす` を使ったら、
自動のカメラはやめて、そちらを優先すること。

## 9. アニメーション（あとから足したぶん）

アニメーション部屋（`anim.html`）で作った動きを、ゲームで再生します。

| ことば | いみ |
|---|---|
| `アニメ(もの, なまえ)` | その「もの」にアニメを再生させる（`じぶんのモデル()` で作ったもの） |
| `アニメをとめる(もの)` | 再生をやめて もとの姿勢に もどす |
| `プレイヤーのすがた(なまえ)` | プレイヤーの見た目を 自分のモデルに入れかえる。以後 `アニメ(プレイヤー, ...)` が効く |

### 保存の形（`localStorage['kotodama-anims']`）

```json
{
  "あるく": {
    "model": "ひと", "loop": true, "sec": 1.0,
    "tracks": [
      { "part": 0,
        "keys": [
          { "t": 0.0, "pos": {"x":0,"y":0,"z":0}, "rot": {"x":0.4,"y":0,"z":0} },
          { "t": 0.5, "pos": {"x":0,"y":0,"z":0}, "rot": {"x":-0.4,"y":0,"z":0} }
        ] }
    ]
  }
}
```

- `part` はモデルの `parts` の番号（0から）
- `pos` / `rot` は もとの姿勢からのズレ（`rot` はラジアン）
- キーの間は線形補間。`loop` のときは 最後→最初 もつなぐ

### 使う人の流れ（ここがつながって初めて意味がある）

    モデリング部屋で「ひと」を作る
      → アニメ部屋で「あるく」を作る
      → ことだまに 2行 はりつける
           プレイヤーのすがた("ひと")
           アニメ(プレイヤー, "あるく")
      → 自分のキャラで 自分の歩き方で あそべる
